# Claude Code を「飽きずに続く・自分専用に育つ」環境にしている実例 5件

調査日: 2026-10-31（JST）。対象は主に 2026-10-01〜10-31 の X 投稿と、そこからリンクされた GitHub / 記事。

## 結論（先に）
- 「育つ」の実例で一番具体的なのは、Stop フック＋専用サブエージェントで、繰り返し直した指摘を `AGENTS.md` に自動で書き足す構成（例2）。10回の指示と120分の間隔ごとに動く。ただし作者自身が「実際の会話での動作は未テスト」と書いている。
- 論文読みに直結するのは skill「imozuru」（例1）。要約せずに原文を保存し、抜き書きが原文の行と1語でも違えばページを作らない。
- 「飽きない」側の工夫は、Stop フックで応答のたびに小さな変化を出すもの（例3 の名言表示、例4 の休憩提案）。
- 育て方の手順として真似しやすいのは、「自分が繰り返し困っていること」を Claude Code 自身に hook / skill / 設定へ仕分けさせるやり方（例5）。
- 仮説: 「毎回の応答で何か変わる（例3・4）」と「使うほど資産が溜まる（例1・2）」を1つずつ入れて、月に1回例5の仕分けをする組み合わせが合いそう（未検証）。

除外: 「10選」「保存版」系のまとめ、有料のフック販売、手順や数字のない紹介投稿。

## 例1. 論文を芋づる式に掘る skill「imozuru」
- X: https://x.com/iru_cection/status/2110245336182874447 , https://x.com/studio_yebisu/status/2110574328156971471 , https://x.com/sora_biz/status/2113515874149666939
- リポジトリ: https://github.com/MaryCache/imozuru（MIT、約1,400スター、最終更新 2026-10-28）
- 問いと論点を書き出す → 2本の検索サブエージェントで `map.md` を作る → 引用・著者をたどる（OpenAlex）→ 原文を `sources/` に保存。飽和（7割既出）で止める。`/imozuru watch` で arXiv 等の新着を RSS で集める。
- 入れ方: `/plugin marketplace add MaryCache/imozuru` → `/plugin install imozuru@imozuru`

## 例2. Stop フック＋サブエージェントで `AGENTS.md` を育てる「continual-learning」
- X: https://x.com/LLMpsycho/status/2107400051311980899
- リポジトリ: https://github.com/LLMpsycho/continual-learning（Cursor の仕組みを Claude Code 等に移植）
- `UserPromptSubmit` で指示を数え、`Stop` で「指示10回 かつ 前回から120分」なら、サブエージェント `agents-memory-updater` が会話ログ（JSONL）を読み、`## Learned User Preferences` と `## Learned Workspace Facts` だけを更新。変更がなければ書かない。
- 環境変数 `CONTINUAL_LEARNING_MIN_TURNS`（10）、`_MIN_MINUTES`（120）、`_TRIAL_MODE`（1で3回・15分）。
- 注意: README に「実際の会話では未テスト」と明記。

## 例3. 応答のたびにランダムな一文を出す Stop フック
- X: https://x.com/erhankeseli/status/2115384844603605500
- リポジトリ: https://github.com/erhankeseli/claude-code-quotes
- `Stop` フックで `quote.sh` が `~/.claude/quotes.txt` からランダムに1行選び、`{"systemMessage": "..."}` の JSON で出す（素の標準出力は表示されないため）。依存は sh と awk だけ。行を足せば再起動なしで反映。
- メモ: quotes を「読んだ論文の一文」「用語と定義」に替えれば復習カードになる（仮説）。

## 例4. 90分続けたら休憩を勧める Stop フック「agent-recess」
- X: https://x.com/spa335L/status/2108041988176261611
- 記事: https://dev.to/spa335l/my-coding-agent-now-tells-me-to-go-outside-and-a-4-gb-gemma-writes-the-message-531p
- リポジトリ: https://github.com/spa77k/agent-recess
- `UserPromptSubmit` で時刻記録、`Stop` で連続90分超なら提案。文面はローカル Ollama（gemma）が天気に合わせて書き、屋内外の判断はコード側。15分空けばリセット、出したら30分黙る。作者は実際に試して公園に行った。

## 例5. 困りごとを hook / skill / 設定に仕分けさせる手順
- X: https://x.com/kensumi_ai/status/2110020824057184627 ほか2投稿
- 公式の比較表を渡し、「繰り返し困っている3つを mod・フック・スキル・設定のどれで直すか、1行の理由つきの表にして、まだ何も作らないで」と頼む。
- 「圧縮で決まりを忘れる」には公式 Hooks guide の SessionStart `compact` フック（再注入）で対処できる。
- メモ: 月1回この仕分けをして1件だけ足すのが一番軽い回し方（仮説）。

# PlaNet の p と q を整理する

PlaNet 3章には、s_t を作る式がいくつも出てくる。この解説書は、それらが**実は2種類しかない**ことを整理する。

## 結論

**o_t（本物の画像）が入っていれば q（encoder）、入っていなければ p（遷移モデル）。**

| 種類 | SSM 版（3.1節） | RSSM 版（3.2節以降） | ELBO の中での書き方 |
|---|---|---|---|
| **p：遷移モデル（事前分布）** | p(s_t \| s_{t-1}, a_{t-1}) | h_t = f(h_{t-1}, s_{t-1}, a_{t-1}) → p(s_t \| h_t) | KL 項の右側 |
| **q：encoder（近似事後分布）** | q(s_t \| s_{t-1}, a_{t-1}, o_t) | q(s_t \| h_t, o_t) | q(s_t \| o≤t, a<t) |

- 同じ行に並んでいる式は、**全部同じモデルを書き方を変えて表したもの**
- 「q(s_t | h_t)」というものは存在しない。画像を見ないのであれば、それは p(s_t | h_t) になる

## 前提ミニ講義

**事前分布と事後分布**：事前分布はデータを見る前の予想、事後分布はデータを見た後の推定。天気でたとえると、事前分布が天気予報で、事後分布が窓の外を見て確かめた天気。

**条件付き分布 p(A | B) の読み方**：縦棒の右側 B が入力、左側 A が出力（どの値がどれくらいありそうか）。実装では、NN に B を入れると A の分布の μ と σ が出てくる。

**o≤t, a<t**：o≤t は o_1 から o_t まで（今の画像を含む）。a<t は a_1 から a_{t-1} まで（今の行動は含まない）。a_t は s_t を見てから選ぶ行動なので、s_t を推定する時点ではまだ存在しない。

## 要点

1. p は「画像を見ずに次の s を予測する」モデルで、本物の環境の遷移を近似する。これが世界モデルの本体
2. q は「本物の画像を見て今の s を推定する」モデル。現実の観測がモデルに入る唯一の入口
3. 学習では KL 項で「p の予測」を「q の推定」に近づける。これで遷移モデルが鍛えられる

## 書き方が3通りある理由

### p：なぜ s_{t-1} 版と h_t 版があるのか
3.1節では、まず h のない一般的なモデル（SSM）を考えるので p(s_t | s_{t-1}, a_{t-1}) と書く。3.2節で「記憶を運ぶ決定的な道 h」を足すと、同じ処理が2段に分かれる。

```
SSM  ：s_{t-1}, a_{t-1} ──────────────→ s_t
RSSM ：s_{t-1}, a_{t-1}, h_{t-1} → h_t → s_t
```

3.1節の式は仮の表記ではなく、遷移モデルそのものを h なしで書いたもの。

### q：なぜ3つの書き方があるのか
- **q(s_t | o≤t, a<t)**：ELBO を書くときの書き方。「何を見ているか」だけを書いていて、内部の作り方は書いていない
- **q(s_t | s_{t-1}, a_{t-1}, o_t)**：SSM での作り方。過去は s_{t-1} を通して受け取る
- **q(s_t | h_t, o_t)**：RSSM での作り方。過去は h_t を通して受け取る

3つとも同じものを指している。q(s_t | h_t, o_t) が実質的に o≤t と a<t を見ていることは、展開すると確かめられる。

```
s_1 ← q(h_1, o_1)            h_1 は初期値（ゼロ）なので、VAE の encoder と同じ
h_2 = f(h_1, s_1, a_1)       h_2 には o_1（s_1 経由）と a_1 が入る
s_2 ← q(h_2, o_2)            s_2 は o_1, o_2, a_1 を見ている
h_3 = f(h_2, s_2, a_2)
s_3 ← q(h_3, o_3)            s_3 は o_1〜o_3, a_1〜a_2 を見ている
```

### ∏ の式
q(s_{1:T} | o_{1:T}, a_{1:T}) = ∏_t q(s_t | h_t, o_t) は、「系列全体の encoder」を時刻ごとの掛け算に分けたもの。各時刻が独立なのではなく、**上の展開を t = 1 から順に回す手順**を表している（h_t が過去の s から作られるので、つながっている）。

| VAE | PlaNet |
|---|---|
| x（画像1枚） | o_{1:T}（画像の系列） |
| z | s_{1:T}（状態の系列） |
| encoder q(z \| x) | q(s_{1:T} \| o_{1:T}, a_{1:T}) |
| 事前分布 p(z) = N(0, I) | 遷移モデル p(s_t \| h_t) |

## 記法の読み下し

| 式 | 入力 | 出力 | 実装 |
|---|---|---|---|
| h_t = f(h_{t-1}, s_{t-1}, a_{t-1}) | 前の記憶・状態・行動 | ベクトル1つ（決定的） | GRU の1ステップ |
| p(s_t \| h_t) | h_t | s_t の正規分布 | MLP で μ, σ を出す → サンプルする |
| q(s_t \| h_t, o_t) | h_t と本物の画像 | s_t の正規分布 | CNN(o_t) と h_t をつないで MLP で μ, σ を出す → サンプルする |

p と q の違いは、**入力に o_t があるかないかだけ**。

## CarRacing での具体例

s のうち「車の横位置」だけを考える（数値は説明用）。

- 時刻 t-1：車はコースの中央（位置 0.0）、ハンドルを右に切った（a = +1）
- **p(s_t | h_t)**：「右に切ったから、たぶん 0.3 くらい」→ N(0.3, 0.2²)。画像を見ていないので幅が広い
- **q(s_t | h_t, o_t)**：本物の画像を見ると、実際は芝生で滑って 0.5 にいた → N(0.5, 0.05²)。画像を見たので幅が狭い
- **KL 項**：p の 0.3 と q の 0.5 のずれを罰する → 遷移モデルは「芝生では滑る」ことを学ぶ

## 学習時と行動時での使い分け

| | 学習時 | 行動時：今の状態の推定 | 行動時：未来の想像（プランニング） |
|---|---|---|---|
| h_t = f(…) | 使う | 使う | 使う |
| q(s_t \| h_t, o_t) | 使う（本物の画像で） | 使う（本物の画像で） | ― |
| p(s_t \| h_t) | KL 項の相手として使う | ― | **使う**（画像なしで s を作る） |
| p(o_t \| h_t, s_t) | 再構成項で使う | ― | ― |
| p(r_t \| h_t, s_t) | 報酬の損失で使う | ― | **使う**（行動列を評価する） |

行動するときの流れ：
1. 本物の画像 o_t を受け取り、q で今の s_t を推定する（出発点を現実に合わせる）
2. そこから p で何ステップも先を想像し、報酬が最大になる行動列を探す（CEM）
3. その行動列の最初の1手だけを実行して、1. に戻る

## World Models との差分

| | World Models | PlaNet |
|---|---|---|
| encoder | VAE の encoder q(z_t \| o_t)：今の画像だけを見る | q(s_t \| h_t, o_t)：記憶も見る |
| 遷移モデル | MDN-RNN P(z_{t+1} \| z_t, a_t, h_t) | p(s_t \| h_t) |
| 事前分布 | VAE では N(0, I)、MDN-RNN は別に学習する | 遷移モデルそのものが事前分布 |
| 学習 | VAE → MDN-RNN の順に別々 | 1つの ELBO で全部まとめて |

## 先回り FAQ

**Q. q(s_t | h_t) の掛け算ではダメなの？**
A. o_t を外すと p(s_t | h_t) と同じものになる。すると本物の画像がモデルに入る経路がなくなり、KL は q = p にすれば 0 になるので、遷移モデルは何も学ばない。

**Q. 状態遷移確率としてモデル化しているのは q？**
A. p。q は画像を見ているので、遷移ではなく「観測からの推定」。

**Q. 行動するとき、出発点の s_t は遷移モデルで作るの？**
A. まず f で h_t を予測し、そのあと q で本物の画像を見て修正する（予測 → 修正）。遷移モデルだけで進むと、少しずつ現実からずれていく。

**Q. q に入れる o_t は、decoder が予測した画像？**
A. いつも本物の画像。decoder の出力は、学習で本物と比べるためだけに使う。

**Q. p(s_t | s_{t-1}, a_{t-1}) と p(s_t | h_t) は別のモデル？**
A. 同じモデル。h を足して2段に分けて書いたのが後者。

**Q. なぜ p は「事前」なの？過去は見ているのに。**
A. 「事前」は「今の画像 o_t を見る前」という意味。過去を見ているかどうかではない。

**Q. 確率分布の高さは確率？**
A. s は連続値なので確率密度。相対的な「ありそうさ」で、1 を超えることもある。

## 理解チェック

1. p(s_t | h_t) と q(s_t | h_t, o_t) のうち、プランニング中に使えるのはどちらか。理由も答えよ。
2. q(s_t | h_t, o_t) が「実質的に o≤t を見ている」理由を、t = 3 まで展開して説明せよ。
3. KL(q ‖ p) を小さくすると、なぜ遷移モデルが賢くなるのか。

<details><summary>答え</summary>

1. p。プランニング中は未来の画像がまだ存在しないので、o_t を必要とする q は使えない。
2. s_1 が o_1 から、h_2 が s_1 から、s_2 が h_2 と o_2 から作られ……と、過去の画像の情報が s → h の順に受け渡されていくから。
3. q は本物の画像を見た答えなので、p をそれに近づけることは「画像を見ずに正しく未来を予測する」練習になるから。

</details>
